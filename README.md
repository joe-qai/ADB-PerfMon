### ADB_Monkey_Performance工具介绍
```
采用python3 + tkinter + adb 技术实现对Android APP应用的性能监控，包括内存、cpu、流量、电量等指标的监控；
同时它支持测试app应用每次启动的耗时及monkey测试，即monkey和性能测试同时进行；
```
- 注意：执行环境必须添加adb环境变量；且有python环境安装对应的依赖。

#### 功能介绍 
```
这是一个适用于android sdk的小工具,可以实现app性能测试：收集cpu，内存，流量，测启动时间，monkey测试等.
```
- 友情提示：cpu和mem信息统一有top命令获得百分比计算app进程所消耗的cpu及内存信息；唯独流量的计算原本的两个方法都不适用了。

#### 注意事项
- 在采集cpu占有率，上传下载流量，内存，启动app耗时的时候采用了线程的方式，不启用线程的话tkinter的界面会有卡死现象！
