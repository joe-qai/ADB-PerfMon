ADB PerfMon

Android 性能测试工具

基于 Python + ADB 的自动化性能监控解决方案，实时监控 CPU、内存、流量等关键指标

🚀 开始使用 📋 了解更多

核心功能

⚡

CPU 监控

实时采集应用 CPU 占用率，支持多进程监控和历史数据分析

💾

内存监控

精确测量应用内存使用情况（PSS/RSS），识别内存泄漏问题

📊

流量统计

统计应用上传/下载流量，帮助优化网络请求效率

⏱️

启动时间测试

精确测量应用冷启动/热启动耗时，优化应用启动速度

🐒

Monkey 测试

支持与性能监控同时进行的自动化压力测试

📈

可视化报告

自动生成 Excel 报告和图表，便于数据分析和汇报

使用流程

1

配置 ADB 环境

确保 ADB 已添加到系统环境变量，验证设备连接状态

2

连接设备

通过 USB 连接 Android 设备，确保设备已授权调试

3

设置测试参数

输入目标应用包名，配置采样间隔和测试时长

4

开始测试

启动性能监控或 Monkey 测试，实时查看数据

5

生成报告

测试结束后自动生成 Excel 报告和可视化图表
